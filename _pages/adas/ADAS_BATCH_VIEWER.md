    <h2>Overview</h2>
    <p>The ADAS Batch Viewer is a lightweight tool for visualizing simulation outputs and scenario playback. It supports batch runs and quick inspection of traces.</p>

    <h3>Features</h3>
    <ul>
      <li>Scenario playback with time controls</li>
      <li>Overlay of sensor data and trajectories</li>
      <li>Batch result comparison and export</li>
    </ul>
